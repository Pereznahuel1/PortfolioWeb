# Portfolio Web Personal - Nahuel Perez

## Descripción breve del proyecto
Portfolio web personal desarrollado desde cero para presentar información profesional, académica, habilidades y proyectos destacados en el ámbito del desarrollo de software.

## Tecnologías utilizadas
* **HTML5** (Estructura semántica: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
* **CSS3** (Diseño visual, Flexbox, CSS Grid y Responsive Design con Media Queries)
* **JavaScript** (Interactividad, manipulación del DOM, eventos y validación de formularios)
* **Git y GitHub** (Control de versiones y gestión del repositorio)

## Principales funcionalidades
* Menú de navegación fijo con desplazamiento suave.
* Sección de inicio interactiva con manipulación del DOM mediante JavaScript.
* Galería de proyectos estructurada con CSS Grid y vistas detalladas.
* Formulario de contacto con validación en tiempo real de campos vacíos y formato de correo electrónico mediante JavaScript.
* Diseño completamente adaptable (*Responsive Design*) para dispositivos móviles y de escritorio.

## Instrucciones para visualizar el proyecto
1. Clonar el repositorio o descargar el código fuente.
2. Abrir la carpeta del proyecto en un editor de código (como VS Code).
3. Abrir el archivo `index.html` en cualquier navegador web moderno.
